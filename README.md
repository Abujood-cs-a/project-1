# 🎨 Leon — Agency Landing Page

A clean, responsive one-page landing page for a creative agency, built with pure HTML & CSS.

## ✨ Features

- Fully responsive (mobile, tablet, desktop)
- Smooth scroll navigation
- Flexbox & Grid layouts
- Hover animations on service & portfolio cards
- Scroll-to-top button

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| HTML5 | Markup |
| CSS3 | Styling (Flexbox, Grid, Variables) |
| Normalize.css | Cross-browser consistency |
| Font Awesome | Icons |
| Google Fonts | Typography (Work Sans) |

## 📁 Project Structure

```
├── HTML/

├── CSS/
```

## 🚀 Getting Started

Clone the repository:
```bash
git clone https://github.com/<your-username>/<repo-name>.git
```

Open the project folder, then open `HTML/index.html` in your browser.

No dependencies, no build step — just open and go.
